# vk-remove-comments

Удаляет все ваши комментарии ВКонтакте по архиву данных. Бесплатно, с открытым кодом, работает прямо в браузере.

**→ [Открыть страницу](https://mikhailsdv.github.io/vk-remove-comments/)**

## Как это работает

У ВК нет способа получить список всех ваших комментариев, поэтому их не умеют удалять ни сам ВК, ни большинство «чистильщиков». Зато ВК по запросу выдаёт архив с вашими данными, а в нём есть ссылки на все комментарии.

- Страница достаёт ссылки из архива прямо в браузере. Архив никуда не загружается.
- Перед удалением каждого комментария она проверяет через API ВК, что его автор — вы. Чужой комментарий не будет удалён, даже если вы админ сообщества или это ваша стена.
- Удаляет до 8 комментариев за запрос и соблюдает ограничения ВК на частоту запросов. Прогресс сохраняется: если что-то прервётся, можно продолжить с того же места.

## Пошагово

1. **Запросите архив.** Откройте [«Защиту данных»](https://vk.ru/data_protection?section=rules&scroll_to_archive=1) ВКонтакте и запросите архив, отметив только «Комментарии». Когда он будет готов, ВК пришлёт уведомление; обычно это занимает от нескольких часов до пары дней. Скачайте zip-архив, распаковывать его не нужно.
2. **Откройте [страницу](https://mikhailsdv.github.io/vk-remove-comments/)** и перетащите на неё архив. Подойдёт и распакованная папка или html-файлы из папки `comments`.
3. **Получите доступ.** Нажмите «Получить доступ через VFeed», в ВК нажмите «Разрешить». Откроется пустая страница с предупреждением: скопируйте её адрес **целиком** из адресной строки и вставьте на странице. Если VFeed не сработал, там же есть запасные приложения.
4. **Проверьте без удаления.** Страница посчитает, сколько комментариев ещё существуют и точно ваши. Ничего не удаляется.
5. **Удалите.** Нажмите «Удалить комментарии» и не закрывайте вкладку до конца. Страница покажет прогресс и примерное оставшееся время. Если ВК начнёт ограничивать запросы, удаление замедлится, но продолжится само.
6. **Отключите доступ** приложения в настройках VK ID, в списке подключённых сервисов и приложений. Если не отключать, он всё равно истечёт сам через сутки.

Архива ещё нет, а удалить нужно пару комментариев? На шаге 1 можно просто вставить ссылки на них. Ссылка копируется, если нажать на дату комментария.

## Безопасность

ВК на странице с токеном предупреждает: не вставляйте этот адрес на сторонние сайты. Совет правильный, ведь с токеном можно управлять вашей стеной. Поэтому страница устроена так:

- **Токен не покидает браузер.** Он хранится только в памяти вкладки и не сохраняется даже в браузере. Запросы уходят только в API ВК (`api.vk.ru`).
- **Браузер не даст отправить его куда-то ещё.** Политика безопасности страницы (CSP в [index.html](index.html)) разрешает загружать скрипты только с самой страницы и с API ВК и запрещает любые другие сетевые запросы.
- **Права минимальные.** Доступ запрашивается только к стене и истекает через сутки.
- **Код открыт.** Вся логика — в [lib.js](lib.js) и [app.js](app.js), без сторонних библиотек и сборки.
- **Можно работать без сайта.** [Скачайте репозиторий](https://github.com/mikhailsdv/vk-remove-comments/archive/master.zip), распакуйте и откройте `index.html` двойным кликом. Страница работает с диска так же, как с сайта.

## Если что-то пошло не так

- **«Архив, похоже, от другой страницы ВК».** Архив запрошен с одного аккаунта, а доступ получен для другого. Удалить можно только свои комментарии, поэтому войдите в ВК под тем аккаунтом, с которого запрашивали архив, и получите доступ заново.
- **«ВК не принял токен».** Токен истёк или скопирован не полностью. Получите новый; если не выходит через VFeed, попробуйте запасное приложение.
- **«ВК просит не торопиться».** Это защита ВК от флуда. Страница сама сделает паузу и продолжит. Если ограничение не снимается, она остановится и предложит подождать 10–15 минут.
- **«ВК исчерпал дневной лимит».** У ВК есть суточный лимит на удаление. Прогресс сохранён: вернитесь позже, загрузите тот же архив и нажмите «Продолжить удаление».
- **Капча.** Страница покажет картинку или ссылку на проверку ВК. После ввода удаление продолжится.
- **Нет связи с ВК.** Проверьте интернет. Если у вас включена программа обхода блокировок, отключите её на время удаления.
- **Удалились не все комментарии.** Часть комментариев удалить невозможно: запись уже удалена, сообщество закрыто или заблокировано, автор записи закрыл профиль или занёс вас в чёрный список. Такие комментарии попадают в «Уже нет или нет доступа». Список неудалённых можно скачать в конце.
- **Комментарии к фото, видео и товарам** пока не удаляются: страница их считает и показывает отдельно.

## Для разработчиков

Сборки и зависимостей нет: это статическая страница из нескольких файлов.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и CSP |
| `style.css` | стили, светлая и тёмная темы |
| `theme.js` | переключатель темы; подключён в `<head>`, чтобы тема применялась до отрисовки |
| `lib.js` | логика без DOM: разбор токена, ссылок и zip, VKScript для `execute`, разбор ответов |
| `app.js` | интерфейс, JSONP-запросы к API, очередь удаления, сохранение прогресса |
| `test/lib.test.js` | тесты `lib.js` |

API ВК не поддерживает CORS, поэтому запросы идут через JSONP (параметр `callback`).

Запустить тесты (нужен Node.js 18+):

```bash
node --test
```

Открыть страницу локально через сервер:

```bash
python3 -m http.server 8765
```

Затем откройте <http://localhost:8765>.

Старая консольная версия (`node index.js`) больше не поддерживается. Она осталась в истории репозитория.
